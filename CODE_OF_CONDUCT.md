# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, no harassment, no personal attacks, and keep
discussion about the project. Maintainers may edit or remove comments, issues and pull
requests that break these rules, and may block repeat offenders.

Report problems privately to the maintainer via the contact on the GitHub profile of
[tonieninja](https://github.com/tonieninja).
