# Zenith palette

| Name        | Hex       | Where                      |
|-------------|-----------|----------------------------|
| Night top   | `#1a2133` | tile gradient start        |
| Night base  | `#0a0c12` | tile gradient end          |
| Sky light   | `#9cc6ff` | Z gradient start           |
| Zenith blue | `#5b9dff` | Z gradient middle, accents |
| Deep blue   | `#2f6fd4` | Z gradient end             |
| Sun         | `#ffffff` | the dot, fades to `#b9d6ff`|
| Muted text  | `#9aa3b8` | taglines on banners        |

Fonts used on banners: Outfit (wordmark) and Inter (tagline). Both are free on Google Fonts.
